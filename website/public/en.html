Different formats, one gesture: select a file, press space.

Markdown

READMEs, notes, drafts. Tapeek sets them in GFM and shows the result.

  • GFM layout Headings, lists, tasks, tables, code, and quotes keep their order.
  • front matter Moves into a document card. It does not mix with the body text.
  • Follows the system Light and dark switch automatically. A 500 KB document appears in about 1 second.

ZIP

Look inside before you extract.

  • Folder tree File sizes, item count, and size before and after compression.
  • Error states Encrypted, empty, damaged, and truncated archives each get a clear message.
  • Chinese names and ZIP64 Both display correctly. Tapeek only reads the archive and never extracts it.

Small on purpose.

No account. No server. No network request. Parsing runs on your Mac, and Tapeek only reads the file.

Download for Mac

  1. Put it in Applications

    Open Tapeek-0.2.0.dmg and drag Tapeek to Applications (/Applications). Or download the ZIP, extract it, and move the app to the same folder.

  2. Turn on Quick Look

    System Settings › General › Login Items & Extensions › Quick Look. Turn on Tapeek.

  3. Select a file and press space

    .md files become documents. .zip files become folder trees.

Terminal 
xattr -dr com.apple.quarantine /Applications/Tapeek.app
open /Applications/Tapeek.app

The command removes the quarantine flag from this app only. It does not change other files.

The first launch may take one more step

Tapeek uses an ad-hoc signature. Apple did not notarize it. If macOS blocks the first launch, right-click the app and choose Open, or run the command to remove the quarantine flag.

If you install in ~/Applications, change the app path in the command to ~/Applications/Tapeek.app.
