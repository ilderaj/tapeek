# 宿主 App 规格（F4）

## 1. 范围

宿主 App 是预览扩展的容器和安装入口。它不负责渲染预览，不保存文档，不提供主题或解析设置。首版只有一个窗口、一页说明和两个动作按钮。

不覆盖：偏好设置、账户、同步、历史记录、文件浏览器、编辑器、更新器、菜单栏常驻。

## 2. 窗口

| 项 | 规格 |
| --- | --- |
| 类型 | 普通 macOS 窗口，单窗口 |
| 默认尺寸 | 640 × 480 pt |
| 最小尺寸 | 520 × 420 pt |
| 标题 | `Tapeek` |
| 关闭行为 | 关闭最后一个窗口后退出 App |
| 外观 | 跟随系统浅色/深色 |
| 菜单栏 | 使用系统默认菜单，不添加自定义常驻项 |
| 背景 | 系统窗口背景，不铺自定义大图或渐变 |

窗口内容垂直排列，窄窗口下不出现横向滚动。

## 3. 内容

### 3.1 标题区

- 应用图标或一个简洁的文档/预览图形。首版可以使用 SF Symbol `doc.text.magnifyingglass`，不强制设计独立图标。
- 标题：`Tapeek`
- 副标题：`在 Finder 中按空格，直接阅读 Markdown 和 ZIP。`

不使用宣传口号、夸张形容词或感叹号。

### 3.2 三步说明

按顺序展示：

1. `打开「系统设置」→「通用」→「登录项与扩展」→「Quick Look」。`
2. `启用 Tapeek。`
3. `回到 Finder，选中 .md 或 .zip 文件，按空格。`

每个步骤有编号或图标，文字可选中。系统设置路径若在当前 macOS 版本变化，以实际系统为准，并在验收记录中注明。

### 3.3 状态说明

显示一个次要信息块：

```
扩展状态由系统管理，App 无法可靠读取。
如果预览没有出现，请确认 Tapeek 扩展已启用，并尝试重新打开 Finder。
```

要求：

- 不伪造「已启用」或「未启用」状态。
- 不通过 shell 调用 `pluginkit` 检测状态。
- 不显示无法验证的绿色勾选或警告图标。
- 文案说明可执行的下一步。

### 3.4 按钮

| 按钮 | 动作 | 失败处理 |
| --- | --- | --- |
| 打开扩展设置 | 尝试打开系统设置的扩展页面 | 失败时打开系统设置首页，并在按钮下方显示「请手动进入『通用』→『登录项与扩展』。」 |
| 查看示例文件 | 在 Finder 中显示内置的示例 Markdown 和 ZIP | 示例资源缺失时，按钮下方显示「示例文件缺失，请重新安装 Tapeek。」 |

设置 URL 首选：

```
x-apple.systempreferences:com.apple.ExtensionsPreferences?extensionPoint=com.apple.quicklook.preview
```

若 `NSWorkspace.open` 返回失败，回退到：

```
x-apple.systempreferences:com.apple.ExtensionsPreferences
```

再失败则打开 `System Settings.app`，不弹出自定义错误对话框。

示例文件：

- 宿主 App 的 Resources 中包含 `gfm.md` 和 `typical.zip`。
- 按钮使用 `Bundle.main.url(forResource:withExtension:)` 定位，然后 `NSWorkspace.shared.activateFileViewerSelecting([url])`。
- 只显示文件，不自动打开预览，不复制到用户目录。

### 3.5 页脚

一行次要文字：

```
本地处理 · 只读预览 · 不联网
```

可以附带版本号：`版本 0.1`，从 `CFBundleShortVersionString` 读取，不写死。

## 4. 交互与状态

- 启动后窗口居中，获得焦点。
- 所有按钮可用键盘聚焦，回车触发。
- 按钮动作执行后不改变窗口布局，不弹出成功提示；设置页或 Finder 本身就是反馈。
- 设置打开失败时，在按钮下方显示一行内联文字，3 秒后可保留，不需要自动消失。
- 示例文件缺失时，显示内联文字，不崩溃。
- 不显示加载指示器；没有网络或异步任务。

## 5. 隐私与权限

- 不请求网络权限。
- 不读取用户文档。
- 不写入 `~/Library`、`~/Downloads` 或项目目录。
- 不收集分析数据、不发送崩溃报告、不集成第三方 SDK。
- 沙盒开启；除打开系统设置和显示自身 bundle 内的示例外，不需要文件访问权限。
- 不申请 Apple Events、辅助功能或全盘访问。

## 6. 可访问性

- 标题、副标题、步骤和按钮都有可读的辅助功能标签。
- 支持 VoiceOver 按顺序朗读。
- 支持系统放大字体时内容不被截断；必要时窗口可滚动。
- 对比度满足系统默认语义色，不自定义低对比度配色。
- 不使用仅靠颜色传达状态的信息。

## 7. 布局细节

- 外边距 32 pt。
- 标题区与步骤区间距 24 pt。
- 步骤之间 12 pt。
- 状态块背景为次要背景色，圆角 8，内边距 12。
- 按钮横向排列；窄窗口下自动换行或纵向排列。
- 页脚与内容之间使用分隔线或 24 pt 间距。
- 不使用卡片套卡片、渐变、发光或装饰性插图。

## 9. 已知限制

- App 无法可靠读取 Quick Look 扩展的启用状态；只提供手动检查步骤。
- 系统设置页面的 URL 可能随 macOS 版本变化，需要回退路径。
- 首版不提供偏好设置；字号、主题、展开层级使用固定默认值。
- 示例文件是只读资源，不随用户修改更新。
