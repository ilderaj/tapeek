# Tapeek App 图标设计说明

## 设计意图

Tapeek 是 Quick Look 里的轻量阅读工具。图标要让用户在 Finder、Dock 和快速预览场景中一眼认出两件事：

1. 这是一份文档；
2. 它会被放大、检查或预览。

构图因此保持为一个连续圆角底板上的两张错位纸张，右下角用珊瑚橙放大镜收束视觉。没有字母、文字、SF Symbols 或外部图形，所有形状都由 CoreGraphics 自绘。

## 画布与轮廓

- 画布：1024 × 1024，透明背景，RGBA。
- 主板：860 × 860，起点 (82, 82)，占画布约 84%。
- 轮廓：指数 4.8 的超椭圆（squircle）连续圆角，不是普通圆弧圆角矩形。
- 安全边距：主板四边各 82 px；投影落在透明画布内，未触碰边缘。
- 主板有轻微向下投影、顶部内高光和一圈低对比描边，保证在浅色和深色桌面上都能分离，但不过度发光。

## 配色

| 用途 | 色值 |
| --- | --- |
| 背景渐变：深海军蓝 | `#081A2B` |
| 背景渐变：中间调 | `#0B3446` |
| 背景渐变：青绿色 | `#0A625C` |
| 后层纸张：顶部 / 底部 | `#E9F3ED` / `#C9E2DC` |
| 前层纸张：顶部 / 底部 | `#FFFDF7` / `#EFF3EC` |
| 标题文字线 | `#173F47`，86% 不透明度 |
| 正文文字线 | `#567779`，60% 不透明度 |
| ZIP 拉链 | `#3D7773`，58% 不透明度 |
| 放大镜外环渐变 | `#FFC27F` → `#FF9A5A` → `#DF5034` |
| 放大镜手柄渐变 | `#FFAF6D` → `#E85C3D` |

| 镜片文字线 | `#1D4A50`，62%–76% 不透明度 |

背景只使用海军蓝到青绿的对角渐变。没有紫色、霓虹发光、粒子或大面积装饰。

## 构图

- 后层纸张位于左上，略微偏出前层，形成清晰的 L 形露边。
- 后层左侧用竖向虚线和成对短齿表示 ZIP；齿距与前层文字线保持同一套几何语言。
- 前层纸张略向右下错位，包含一条较粗标题线和三条正文线，共四条抽象文本线。
- 右下角放大镜外径 232 px、环宽 34 px。镜片是暖白半透明材质，内部有四条文档线，暗示“预览/放大阅读”。
- 手柄向右下延伸，与圆角底板的内边缘留出足够距离。
- 纸张和放大镜整体向左、向下微调，使视觉重心落回画布中心。
- 前后层各有轻微投影，前层投影落在后层纸张上，保持材质层次但不影响轮廓识别。

## 尺寸策略

Xcode 的 macOS AppIcon 使用 1x/2x 槽位。`Contents.json` 采用标准 10 个槽位，物理像素覆盖 16、32、64、128、256、512 和 1024：

| 物理像素 | 文件 |
| --- | --- |
| 16 | `icon_16x16.png` |
| 32 | `icon_16x16@2x.png`、`icon_32x32.png` |
| 64 | `icon_32x32@2x.png` |
| 128 | `icon_128x128.png` |
| 256 | `icon_128x128@2x.png`、`icon_256x256.png` |
| 512 | `icon_256x256@2x.png`、`icon_512x512.png` |
| 1024 | `icon_512x512@2x.png` |

所有尺寸都由同一张 `docs/assets/tapeek-icon.png` 母版通过 `sips -z` 缩小得到，没有单独绘制小尺寸版本。

小尺寸策略：

- 32 px 时保留“两张浅色纸 + 橙色镜环”的主轮廓，ZIP 齿和正文线退化为纹理，不承担识别任务。
- 16 px 时进一步简化为“浅色文档块 + 橙色预览点”；不承诺读出任何内部线条。
- 不使用自适应或手调小图，避免不同尺寸的造型漂移。

## 生成方式

```sh
swift scripts/make-app-icon.swift
```

脚本只导入系统框架（Foundation、CoreGraphics、ImageIO、UniformTypeIdentifiers），不联网，不读取第三方依赖。它完成两件事：

1. 绘制并写出 1024 × 1024 母版到 `docs/assets/tapeek-icon.png`；
2. 用系统工具 `sips` 从该母版生成 `TapeekApp/Assets.xcassets/AppIcon.appiconset/` 中的 10 个 Xcode 槽位文件。

## 目视检查

已实际查看 1024、256、128、64、32 和 16 px 输出：

- 1024：两张纸、ZIP 齿、放大镜层次完整，四角和边缘没有裁切。
- 32/64：文档叠层和橙色放大镜可辨。
- 16：只保留文档色块和橙色镜环，符合极小尺寸的预期，不当作可读细节。
- 四个角像素 alpha 为 0；没有白底或画布边框。
