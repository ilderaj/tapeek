# Tapeek 0.2.0

- 修复大型 Markdown 的围栏代码块被错误分块的问题：较短围栏、不同标记或带正文的结束行不再提前关闭代码块，并新增回归测试。
- 整理 ZIP 解析器的格式与局部命名，便于阅读和维护，保留原有控制流、边界检查和限制。
- 新增可重复执行的 Release 打包脚本，生成 DMG、ZIP 和 `SHA256SUMS`，并同步中英文下载说明。

需要 macOS 27 和 Apple 芯片（arm64）。源码构建需要 Xcode 27 和 `xcodegen`。

安装：打开 `Tapeek-0.2.0.dmg`，把 Tapeek 拖到 Applications（`/Applications`）；也可以解压 `Tapeek-0.2.0.zip` 后把 App 移到该目录。随后在「系统设置」→「通用」→「登录项与扩展」→「Quick Look」中启用 Tapeek。

发行包使用 ad-hoc 签名，未经过 Apple 公证。若首次打开被 Gatekeeper 拦截，可右键 App 选择「打开」，或执行：

```sh
xattr -dr com.apple.quarantine /Applications/Tapeek.app
open /Applications/Tapeek.app
```

若安装到 `~/Applications`，请相应调整命令路径。下载校验文件与安装包到同一目录后，可运行 `shasum -a 256 -c SHA256SUMS` 验证。

验证：68 项 Core 测试全部通过，0 失败、0 跳过；18 个已提交 ZIP 样本及所需大样本通过严格校验。Release 构建成功，ZIP 解压后的 App、挂载 DMG 中的 App 及两者的预览扩展均通过严格签名检查；版本均为 0.2.0（build 2），最低系统为 macOS 27，架构为 arm64。DMG 校验和与发行包 SHA256 校验均通过。

Developer ID 签名、公证和新的 Finder 界面检查尚未执行。现有 SwiftLint 复杂度和函数长度等诊断仍保留，未作为此次发布的通过条件。
