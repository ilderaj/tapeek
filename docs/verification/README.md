# 验收记录

本目录存放每个 ticket 的验收证据。命名规则：

- `Txx.md`：ticket 的验收记录。
- `Txx-序号-说明.png`：Quick Look 或宿主 App 截图。
- `Txx-说明.txt`：命令输出、日志、对比结果。

要求：

- 证据来自真实运行，不使用示意图代替。
- 没有运行的项目写「未验证」，不写「应该」。
- 失败项保留原始输出，不只写结论。
- 截图不要覆盖其他 ticket 的文件。
- 完成后的 ticket 才写「结论：通过」；部分完成写「部分通过」并列出未覆盖项。

最终汇总写入 `FINAL.md`，由 T13 生成。初始状态下该文件不存在是正常的。
