## 实现

`ZipTree` 从 `ZipListing` 构建不可变树：根节点 `id/path` 为空，名称取 ZIP 文件名去掉扩展名；按 `/` 分段创建节点，缺失父目录自动合成；显式目录与合成目录合并，保留显式目录的修改时间与加密标记。

子节点排序固定为目录优先，其次 `localizedStandardCompare`，名称相同再按路径升序。`rows(expanded:)` 和 `defaultExpandedIDs()` 都是纯函数，不修改树、不缓存。`fileCount` 统计文件与符号链接；`directoryCount` 统计显式目录和合成目录，不含根。未添加解压、内容读取或文件系统写入。
