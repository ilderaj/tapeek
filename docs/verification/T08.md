## 实现说明

- `ZipPreviewView` 用 `ZipTree.rows(expanded:)` 的纯函数输出渲染，目录展开只改本地 `Set<String>`。
- 头部固定，树在 `ScrollView + LazyVStack` 中按需渲染。
- 摘要和文件大小使用自写 `ByteFormat`，不再依赖系统 locale 的 `ByteCountFormatter`，因此扩展进程为 en-US 时也显示中文单位。
- 目录行显示直接子项数量，文件行显示原始大小；悬停显示完整路径与修改时间。
- 空包、全部跳过、错误分别使用独立状态视图；截断/加密/旧式编码用提示条。
- 未实现解压、打开文件或拖出。
