## 严格检查

`--check` 默认允许大样本缺失，但会明确打印「跳过且未验证」。`--require-large` 要求大样本和 `.build/fixtures/manifest.json` 全部存在，缺失即返回非零。`run-tests.sh` 使用严格模式，并设置 `TAPEEK_REQUIRE_LARGE=1`，`ManifestTests` 在缺少大样本时会失败而不是跳过。

## 性能结果

以下数字只测 Core：Markdown 解码/front matter，ZIP central directory 读取和 `ZipTree` 构建。**不包含 SwiftUI/MarkdownUI 视图构建、布局和 Quick Look 首帧绘制。**

| 样本 | 大小 / 条目 | Debug 中位数 | Release 中位数 | 目标 | 结论 |

| `gfm.md` | 933 B | 0.112 ms | 0.092 ms | ≤ 100 ms | 通过 |
| `large-500kb.md` | 512,040 B | 3.237 ms | 0.661 ms | ≤ 300 ms | 通过 |
| `typical.zip` | 5 条 | 0.269 ms | 0.118 ms | ≤ 50 ms | 通过 |

| `zip64.zip` | 70,000 条（列出 20,000，ZIP64 EOCD） | 382.615 ms | 244.864 ms | ≤ 1 s | 通过 |
