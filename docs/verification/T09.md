## 日志问题与修复

最初用 `log show` / `log stream` 看不到自定义日志。原因是 zsh 把 `log` 解析为内建函数，命令实际没有调用系统日志工具。改用绝对路径后恢复正常：

```sh
/usr/bin/log show --info --last 10m \
  --predicate 'subsystem == "com.local.Tapeek.Preview"' --style compact
```

实际输出：

```text
2026-11-02 12:59:43 I TapeekPreview [com.local.Tapeek.Preview:preview] preview kind=zip duration_ms=2 result=success
2026-11-02 13:05:56 I TapeekPreview [com.local.Tapeek.Preview:preview] preview kind=markdown duration_ms=3 result=success
```

日志只记录文件类型、耗时和结果，不记录路径或文件内容。

## 多文件切换

用一个最小 `QLPreviewPanel` 测试程序在同一个面板中依次加载 `gfm.md` 和 `typical.zip`，3 秒后切换当前预览项。截图显示：

- `T09-01-multi-before.png`：标题 `gfm.md`，Markdown 内容。
- `T09-02-multi-after.png`：标题 `typical.zip`，ZIP 目录树。

同一个窗口从 Markdown 切换到 ZIP，没有残留上一份内容、摘要或错误状态。每次 `preparePreviewOfFile` 都会移除旧 `hostingView` 并新建。
